# Prototype69xbox

> **An experimental 3D web prototype for interactive product exploration.**

A React/TypeScript prototype combining Three.js with a responsive interface for experimenting with real-time 3D scenes, spatial interaction and modern web presentation.

## Highlights

- Three.js-powered 3D rendering
- React component architecture
- Responsive UI foundation
- Supabase-ready application layer
- Fast Vite development workflow

## Stack

React 18 · TypeScript · Vite · Three.js · Tailwind CSS · Supabase

## Run locally

```bash
npm install
npm run dev
```

Build for production:

```bash
npm run build
npm run preview
```
