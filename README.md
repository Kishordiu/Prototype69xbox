> **3D WEB / SPATIAL INTERACTION.**

## THE PREMISE

Prototype69xbox is a spatial web experiment: a product-like interface where the object is not a background image but an interactive 3D surface.

## THE EXPERIENCE

**Treat the viewport as space.**  \n**Let motion explain the object.**  \n**Keep the surrounding UI quiet.**

## THE SYSTEM

Three.js handles realtime 3D rendering while React owns interface composition. The result is a hybrid of scene, product surface and responsive web layout.

## THE STACK

React 18 · TypeScript · Vite · Three.js · Tailwind CSS · Supabase

## RUN

**Requirements:** Node.js 20+ and npm.

```bash
npm ci
npm run dev
```

Vite prints the local development URL in the terminal. To build and preview the production bundle:

```bash
npm run build
npm run preview
```

## PROJECT STATE

**3D interaction prototype**

The repository documents the capabilities that are actually implemented; future integrations are intentionally separated from the current product surface.
